LearnLoop AI - Day 3 AI Backend Merge Patch

This patch contains only new/changed Day-3 AI backend files.
It does NOT contain your .env, .git, .venv, database data, or uploaded study files.

Recommended merge:
1. Commit/back up your current backend.
2. Extract this ZIP.
3. Copy its contents into the ROOT of your existing LearnLoopBackend folder.
4. Allow matching files to be replaced.
5. Keep your existing .env and add the required AI variables manually.
6. Install/update requirements.
7. Run: python -m compileall app
